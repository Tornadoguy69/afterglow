How to help

You do not need to be a programmer to help. The most useful thing anyone has done for this site so far is point out a number that was wrong.

No code · 2 minutes Something here is wrong A number that looks off, a claim that overstates the evidence, a confusing sentence. Tell us the page and what looks wrong. You do not need to be certain, and you do not need a source — several real errors on this site were found exactly this way. Report it → No code · 5 minutes Something is missing Suggest a topic. The ones that work best are the ones you cannot picture from a paragraph — where you have to move something to understand it. Describe what a reader should be able to change, and what they would see. Suggest it → Some JavaScript · an afternoon Build one yourself If you can write a bit of JavaScript, you can add a whole topic. You write the physics and what goes on screen; everything else — the 3D view, the camera, the controls, the charts, dark mode, the narrated tour — is already handled for you. Read on →

What would get it turned down

  
All four of these are real mistakes made while building this site, caught in review.

  

    
A number with no sourceIf a quantitative claim appears on
      screen, its origin appears in meta.json. No exceptions.

    
A relation used out of rangeThe white-dwarf mass relation is
      calibrated above 0.83 M☉. Applied to a 0.2 M☉ star it returned a remnant heavier than the
      star it came from.

    
An approximation sold as exactThe textbook stellar lifetime
      shortcut is wrong by 4× for massive stars. Use real models or say plainly that it is a
      first-order estimate.

    
Physics tuned to look goodTune the rendering freely — exposure,
      bloom, point size, colour scales. Never tune the equations.
