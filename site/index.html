Physics you can poke at, not read about.

Every topic here is a working simulation. The equations run live — change a number and the sky changes with it. Nothing is a pre-rendered animation dressed up as a model.

Each page states plainly how confident the field actually is, because the difference between measured, argued about and untestable is the most important thing in science writing and the first thing usually thrown away.

open source · every claim carries a citation · contributions welcome

How to read the badges

Established

Reproduced, quantitative, not seriously contested. You could look it up in a graduate textbook.

Active research

Real data exists, but no consensus on what it means. Expect this page to change.

Speculative

Interesting, internally consistent, and currently impossible to test. Not the same as knowledge.
